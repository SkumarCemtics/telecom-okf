# Subdirectories

* [databases](databases/index.md) - Contains physical database schema knowledge. This directory includes database-level documentation for the Network and Customer databases, describing their purpose, available tables, relationships, and schema organization used for schema linking and SQL generation.

* [network](network/index.md) - Contains telecom network analytics knowledge. The tables directory contains physical network data sources. The datasets directory contains business analytics domains and analytical use cases. The references directory contains metric definitions, KPI interpretations, and table relationship specifications.

* [customer](customer/index.md) - Contains customer analytics knowledge. The tables directory contains physical customer and customer experience data sources. The datasets directory contains business analytics domains and analytical use cases. The references directory contains metric definitions, customer attributes, business rules, and table relationship specifications.
