# Telecom OKF
 - Telecom OKF (Open Knowledge Framework) is a domain-driven knowledge repository designed to externalize telecom analytics expertise from application code.
 - The framework provides standardized definitions for KPIs, joins, thresholds, business rules, dictionaries, and prompt templates that can be consumed by analytics platforms, AI agents, reporting tools, and SQL generation engines.
## Goals
 - Standardize telecom KPI definitions.
 - Centralize reusable data joins.
 - Support AI-driven metric discovery and SQL generation.
 - Improve consistency across analytics, RCA, and reporting workflows.
 - Enable easy maintenance of domain knowledge by business and analytics teams.
